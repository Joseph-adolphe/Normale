# ScaffTrack1

Application de gestion et suivi de matériel d'échafaudage (Scaffolding Tracking Solution).

## Structure de la Solution
- **ScaffTrack1** : Application cliente .NET MAUI (interface multiplateforme)
- **ScaffTrack.Api** : API Backend ASP.NET Core
- **ScaffTrack.Shared** : Modèles et DTOs partagés entre le client et l'API

## Technologies
- .NET MAUI / C#
- ASP.NET Core Web API
- Architecture MVVM
